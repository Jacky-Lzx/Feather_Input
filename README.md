# Feather Input

macOS 原生中文输入法，Swift / InputMethodKit 前端与 librime 引擎。支持全拼、小鹤双拼、简体输出、中英混合候选、用户词频学习、原生候选窗口和设置窗口。

## 构建

需要 Xcode 命令行工具、Homebrew、Python 3 和 Git：

```sh
brew install librime
scripts/build-app.sh
swift test
```

产物为 `dist/FeatherInput.app`。脚本下载固定版本的官方 Rime 方案与词频数据，打包动态库及 OpenCC 数据，预编译词库，并执行两种方案的真实输入测试。首次构建需要网络。当前验证环境为 Apple Silicon / macOS 26；Swift 源码最低目标为 macOS 13，但 Homebrew 动态库可能要求更新系统，当前生成的包最低为 macOS 26，仅含本机构建的 arm64 架构。打包脚本会按依赖的实际最低版本设置应用元数据。

## 安装与使用

```sh
scripts/install.sh
```

安装脚本会注册输入源并校验系统枚举结果；已启用时跳过重复启用请求，避免更新时重复触发授权弹窗。首次启用或输入源被禁用后，仍由 macOS 请求确认。安装成功后，从菜单栏输入法菜单选择 Feather Input。也可在系统设置 → 键盘 → 文字输入 → 编辑中查看。若系统设置已打开，请关闭后重新打开以刷新列表。输入法使用系统输入接口，无需辅助功能权限。

- 系统输入法菜单：选择全拼、小鹤双拼，或打开设置调整候选字号和横排／竖排。
- `Caps Lock` 或右 `Control` 单独按下并松开：两者均可切换中英文，有未上屏拼音时先确认当前候选。按键以系统收到的键码为准，键盘直接发送右 Control 也支持。
- 在 Feather 内，Caps Lock 用于语言切换，英文保持小写，按 Shift 输入大写。也可通过 `Control + Shift + Space` 或菜单切换。
- 主屏幕左下角常驻“中／英”标识，随 Feather 输入状态更新；其他输入法下隐藏，可在设置中关闭。
- 切换中英文后，在输入光标附近显示“中文”／“英文”约 0.8 秒；继续输入或离开当前输入窗口时提前消失。
- 点击候选或按 `1`–`5` 选词，空格上屏，候选显示时按 `→` 展开全部候选；展开后 `←` / `→` 换列，`↑` / `↓` 在列内选词，空格或回车确认，Esc 收起。普通窗口仍可用 Page Up / Page Down 和 Fn + ↑ / ↓ 翻页，Esc 取消。
- 候选窗不获取键盘焦点；横排过宽时改为竖排，长候选截断显示并提供完整提示，超高列表可滚动。
- 小鹤双拼使用 `nihc` 输入“你好”；不包含小鹤音形。
- 中文模式下可直接输入英文单词并从同一候选窗选择，例如 `github` 会提供规范写法 `GitHub`。英文默认低于常规中文候选，支持前缀补全和用户词频学习；设置中可配置至少输入 1–12 个字符才显示，默认为 3。Return 仍可原样上屏当前输入。
- 数据位置：`~/Library/Application Support/FeatherInput`；方案和字号保存在应用偏好设置中。

更新时运行 `scripts/build-app.sh` 后切换到其他输入法，再运行 `scripts/install.sh`；安装脚本会原子替换旧应用、重启 InputMethodKit 进程、保留已有输入源授权，并在注册失败时恢复旧版本。每次构建都会自动递增本机安装包的 `CFBundleVersion`，避免 macOS 继续使用旧的输入源缓存，无需在系统设置中删除再添加。卸载时才需要先在系统设置中移除输入源，再删除 `~/Library/Input Methods/FeatherInput.app`。用户词库不会被自动删除。

当前为开发预览版，使用本机 ad-hoc 签名；正式分发还需 Developer ID 签名、公证及更多应用兼容性验证。模糊音、词库管理界面暂未实现。

见 [验证记录](docs/verification.md) 和 [第三方来源](THIRD_PARTY_NOTICES.md)。

### 本地 AI 候选推荐（实验功能）

在 LM Studio 的 Developer 页面启动 `127.0.0.1:1234` 服务并加载 Qwen3-0.6B-MLX。打开 Feather 设置，填写 API Token，点击“连接并测试模型”，选择实际模型 ID，再开启“启用本地 AI 候选推荐”。Token 按用户选择明文保存在 `~/Library/Application Support/FeatherInput/lm-studio-token.txt`，文件权限为 `0600`。也可直接编辑该文件，下次请求会重新读取。不再访问钥匙串；旧 Token 需在设置里重新粘贴并保存一次。

停顿 250 ms 后，Feather 异步发送当前拼音、当前页候选，以及本次输入会话最近上屏的最多 80 个字符。不会读取应用文档、剪贴板或其他输入框；移动光标、切换应用或中英文时清空这段上下文。推荐项旁显示 `✦`，仍用原数字或鼠标选择；空格仍选择 Rime 当前高亮项。模型只返回候选编号，不生成或自动上屏新文字。

默认关闭。模型超时、认证失败或返回无效编号时，普通候选照常使用。输入改变后旧请求取消、过期结果丢弃。请求只发往上述本机地址且不跟随 HTTP 重定向。Feather 不保存提示词日志；LM Studio 自身的日志由其设置管理。小模型的推荐质量尚需用实际输入评估，连接测试会显示合成样例的推荐和耗时。

### LLM 调试窗口

从输入法菜单选择“LLM 调试…”，或在设置中点击“打开 LLM 调试窗口”。开启窗口里的“调试模式”后，继续输入即可查看实际请求 JSON、返回正文、HTTP 状态、耗时及错误；设置中的模型发现与连接测试也会记录。取消“跟随最新”可查看旧请求，正文支持选中复制。

调试每次启动默认关闭，仅保留内存中最近 30 条记录，每段正文最多显示 32,000 个字符。不会记录请求头，正文中的当前 API Token 也会隐藏。关闭调试或点击“清空记录”会清除记录，已在途的旧响应不会重新写入。关闭窗口仍会继续记录，直到关闭调试。记录可能包含你正在输入的上下文；Feather 不将调试记录写入文件。

### 上屏后 AI 短语续写（实验功能）

在设置中单独开启“上屏后 AI 短语续写”，使用相同的 LM Studio 模型与 Token；无需开启候选推荐。用 Feather 上屏文字后停顿 400 ms，模型根据当前会话最近上屏的最多 80 个字符预测一个最多 24 字符的短语。完成后在玻璃候选窗中显示“AI 续写 · …”，**点击建议才会插入**，没有编号，不占用空格、Tab 或数字键。不会自动连续生成。

新按键、光标移动、切换输入框等操作会取消建议。响应和点击时都会核对会话版本、前台应用及客户端报告的选区；不读取文档前文，客户端无法报告选区时仍依赖输入事件判断位置。模型结果还会过滤空白、换行、纯数字、超长及明显复述整段前文等情况。续写请求和返回可在 LLM 调试窗口查看。通用 0.6B 模型的输出质量不稳定，建议按需开启。

## 系统安全输入

macOS 开启 Secure Event Input 时，Feather 将按键直接交还系统，不进入 Rime、不读取光标前正文，也不新发起输入预测请求；已有的拼音组合会丢弃而非提交，迟到的候选响应不再采用。退出安全输入后沿用之前的中英文模式。

检测使用 `IsSecureEventInputEnabled()`，这是系统全局状态，并非当前文本框类型：其他进程开启安全输入时也会触发直通。若某个自定义密码框没有开启系统安全输入，此检测无法识别它。合成测试覆盖按键直通与不插入文字；具体权限密码弹窗仍需实际复测。

## 全部候选窗口

输入拼音后按右键展开，每列数量沿用展开前生效的候选数量设置（1–9 个），若已有当前输入的 LLM 评分，则将全部已评分候选按融合分数排列在最前面（可跨多列）；未评分候选按 Rime 原始顺序接续，按全局索引去重。没有有效评分时，沿用展开前当前页的显示顺序作为开头。窗口同时标记当前列和当前候选；每页最多显示 5 列（例如每列 7 个时，每页最多 35 个）。在第 5 列继续按右键会整页切换到第 6–10 列；在新页第 1 列按左键返回上一页。翻页尽量保持当前行，最后一页不足 5 列时只显示剩余结果。左右只切换列并尽量保持行位置，进入较短的最后一列时停在该列最后一行；上下不跨列。只有当前高亮列显示从 1 开始的行编号（每列 7 个时为 1–7），其他列不编号，但每列始终预留固定编号栏，编号显隐不会改变词语位置。按数字键直接选择当前列对应行；最后一列不存在的行号不会选词。也可以直接点击候选。

候选通过 Rime 全局候选迭代接口分批读取，直到没有更多结果，不局限于当前页；加载期间显示“加载中”。选词使用全局候选索引，部分拼音候选仍由 Rime 处理后续未转换内容。展开时冻结整个排序，后续 LLM 响应不会改变展开窗口；评分候选来自普通窗口当前页起的送评范围。Esc 只收起展开窗口，保留拼音；继续输入或删除会退出展开状态并正常编辑拼音。

候选窗口每次显示时，会通过 IMK 读取当前输入窗口的层级，使用“不低于弹出菜单层级，且高于输入窗口一层”的层级。普通候选、展开候选和 LLM 侧窗使用一致的层级策略，不获取键盘焦点。此策略依赖输入应用提供正确的窗口层级，不保证覆盖系统安全界面或其他应用任意层级的覆盖窗口。

### 拼音约束的 AI 新词建议

设置中的「根据上下文和拼音生成新词（实验）」默认开启，需要更新本地 MLX 后端依赖。输入完整的 2–6 个音节后，侧边可以出现最多 3 个 `AI · 词语` 按钮，按 `⌥ Option + 1 / 2 / 3` 或点击上屏。它根据光标前内容和当前全拼／小鹤编码生成新词，能够给出 Rime 候选中没有的组合，例如「落霞与」后输入 `guwu`，模型可建议「孤鹜」。数字键仍用于原来的 Rime 候选；展开网格保持原有融合排序。

候选对比调试面板新增「AI · 拼音生成」列，显示生成排名、模型分数、音节解析、往返及推理耗时；原始请求和响应可在 LLM 调试窗口查看。更完整的算法、时序和限制见 [后端文档](backend/README.md#按拼音生成新词实验)。

### 不显示行内拼音的应用

候选窗口顶部始终显示正在输入的拼音和组合光标；即使 Rime 没有候选（例如小鹤模式输入 `github`），也保留输入文字和操作提示。按 Return 将原始输入上屏，Backspace 删除，Esc 取消。该显示不依赖应用渲染 marked text；安全输入时仍隐藏窗口并直接交给应用处理。

输入框获得输入法焦点（IMK 激活通知）时，会在光标附近显示「中文／英文」。设置中的「焦点状态提示持续到开始输入」默认开启，保留提示直到开始按键或失焦；关闭后按「焦点提示显示时间」自动消失（默认 0.8 秒，可配置 0.1–5.0 秒），下次获得焦点生效。光标布局尚未就绪时会在 400 ms 内短暂重试；开始按键、失焦或安全输入时不再显示待触发的提示。不读取输入框内容，也不新增辅助功能权限；应用未发送 IMK 激活通知时无法触发此提示。

没有文本输入框的应用可能仍会短暂激活输入法。Feather 会检查客户端提供的选区和 Unicode 输入能力；如果选区不可用，字母不会进入 Rime 组合，也不会弹出候选窗口。若已有组合后焦点失去文本输入能力，Esc 会清除 Feather 的组合并关闭窗口。

拼音组合打开时，Caps Lock 和右 Control 暂时不执行中英文切换；按住其中任意一个键，再按 `h/j/k/l` 可按 Vim 方向在候选中移动（左／下／上／右）。离开组合后两个键恢复原来的单键切换功能。
